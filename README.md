# 문맥 추론 점검 모형 · 수업 자료

"말의 뜻은 어떻게 이해되는가?" — 6차시 문해력·AI 융합 수업 자료입니다. 학생 활동과 공개 수업 흐름·교사 결과 관리를 별도 페이지로 제공합니다.

## 폴더 구조

```
index.html        학생 활동 페이지 (앱 1~3)
teacher.html      수업 소개 페이지 (수업 모형 · 수업 흐름 · 결과 대시보드)
config.js         시트 주소, 앱 1 주소, 가명 처리 설정
gas-bridge.js     정적 사이트에서 Apps Script 웹 앱을 부르는 연결 파일
apps/app1.html    앱 1 · 단어만 같으면 뜻도 같을까? (BoW)
apps/app2.html    앱 2 · 주변 단어는 어떤 단서가 될까? (Word2Vec)
apps/app3.html    앱 3 · 같은 낱말, 옆 말로 뜻을 나눌 수 있을까? (다의어)
apps/admin.html   교사 · 앱 3 어구 및 CSV 단어 더미 관리
gas/Code.gs       통합 Apps Script 서버
```

## 페이지 구분

- 학생은 저장소 첫 화면 `index.html`에서 활동 앱을 엽니다.
- `teacher.html`의 수업 모형과 수업 흐름은 홍보 목적으로 로그인 없이 공개합니다.
- 교사 메뉴에서 비밀번호로 로그인하면 앱별 학생 기록과 단어 더미 관리를 이용할 수 있습니다.
- 교사 결과 대시보드와 `apps/admin.html`은 같은 관리자 비밀번호를 사용합니다.
- 결과 화면은 앱별 기록 표, 내용 검색, CSV 내려받기를 제공합니다.

## 데이터 연결과 배포

학생 브라우저는 GitHub Pages에서 화면을 열고 `gas-bridge.js`를 통해 Apps Script 웹 앱으로 기록을 보냅니다. Apps Script는 데이터를 구글 시트에 저장합니다.

1. 새 구글 시트에서 [확장 프로그램] → [Apps Script]를 열고 `gas/Code.gs` 내용을 붙여 넣습니다.
2. 웹 앱으로 배포합니다. 실행 권한은 **나**, 액세스는 **모든 사용자**로 설정합니다.
3. 배포된 `/exec` 주소를 `config.js`의 `API_URL`에 설정합니다.
4. 저장소 [Settings] → [Pages]에서 `main` / `(root)`를 배포합니다.
5. Apps Script 코드를 수정한 뒤에는 배포 관리에서 새 버전을 배포합니다.

새 Apps Script 배포 주소에서 만드는 시트 탭:

- `앱1 기록`: BoW 결과
- `우리반낱말`, `학생기록`: 앱 2 활동 자료와 결과
- `앱3 투표`, `앱3 기록`, `앱3 어구`: 앱 3 투표·결과·어구

## 교사 비밀번호

`teacher.html`과 `apps/admin.html`은 Apps Script 속성의 관리자 비밀번호를 확인합니다. 이미 비밀번호가 설정되어 있으면 기존 비밀번호를 사용하세요. 재설정이 필요하면 Apps Script 편집기에서 `resetAdminPassword`를 한 번 실행한 뒤, 교사 페이지에서 새 비밀번호를 설정합니다. 비밀번호는 소스 파일에 넣지 마세요.

## 단어 더미 CSV

교사 페이지의 **단어 더미 관리**에서 `apps/admin.html`을 열고 CSV를 선택합니다. 첫 행에 다음 열 제목이 있어야 합니다.

`반, 모둠, 단어, 뜻코드, 어구`

파일 미리보기에서 중복과 읽지 못한 줄을 확인한 뒤 창고에 추가하고 저장합니다. 가져온 어구는 처음에는 창고에만 들어가며, 앱 3 수업·점검 자료로 쓰려면 관리 화면에서 쓰임을 선택해야 합니다.

## 개인정보

- 학생 이름은 받지 않습니다. 앱 1~3의 결과 전송에는 학교명과 번호를 씁니다.
- `PSEUDONYMIZE: true`이면 학교명은 전송 전에 가명 코드로 바뀝니다. 번호와 응답 내용은 결과 분석을 위해 시트에 저장됩니다.
- 학생 작업 진행 상태는 각 기기의 브라우저에 저장되고, 제출한 활동 결과는 구글 시트에 저장됩니다.
- 학생 결과는 교사 비밀번호가 확인된 요청에 대해서만 반환됩니다.

## 로컬 미리보기

`API_URL`을 비우면 결과 제출·교사 결과 조회는 서버에 연결되지 않습니다. 로컬 웹 서버를 실행하고 `http://localhost:8000`에서 확인하세요.
