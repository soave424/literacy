# 문맥 추론 점검 모형 · 수업 웹뷰어

"말의 뜻은 어떻게 이해되는가?" — 6차시 문해력·AI 융합 수업을 하나의 화면에서 진행하는 웹뷰어입니다.
왼쪽에는 차시별 지도안(4단계)이, 오른쪽에는 실습 앱이 열립니다.

## 폴더 구조

```
index.html        웹뷰어 (모형 · 1~2 · 3~4 · 5 · 6차시 · 교사)
config.js         ★ 설정 (시트 주소, 앱 1 주소, 가명 처리)
gas-bridge.js     깃허브에서 google.script.run 을 흉내 내는 연결 파일
apps/app2.html    앱 2 · 주변 단어는 어떤 단서가 될까? (Word2Vec)
apps/app3.html    앱 3 · 같은 낱말, 옆 말로 뜻을 나눌 수 있을까? (다의어)
apps/admin.html   앱 3 관리자 · 어구 관리
gas/Code.gs       통합 서버 (구글 시트 + Apps Script 에 붙여 넣는 파일, 깃허브에서는 실행되지 않음)
```

## 구조: 화면은 깃허브, 데이터는 구글 시트

```
학생 브라우저 ──► GitHub Pages (index.html, apps/*.html)
                     │  fetch POST {fn, args}   ← gas-bridge.js
                     ▼
               Apps Script 웹 앱 (gas/Code.gs) ──► 구글 시트 (우리반낱말·학생기록·앱3 투표·앱3 기록·앱3 어구)
```

앱 HTML은 원래 `google.script.run.함수(...)`로 시트와 이야기합니다. `gas-bridge.js`가 같은 이름의 객체를 만들어
그 호출을 Apps Script 웹 앱으로 보내 주므로, 앱 코드는 `<script>` 두 줄만 추가하고 그대로 씁니다.

## 배포 순서

### 1. 서버(시트) 만들기 — 한 번만
1. 새 구글 시트 → [확장 프로그램] → [Apps Script]
2. `gas/Code.gs` 내용을 붙여 넣고 저장
3. [배포] → [새 배포] → 유형 **웹 앱** · 실행: **나** · 액세스: **모든 사용자**
4. 나온 `/exec` 주소를 복사

### 2. 깃허브에 올리기
1. 새 저장소를 만들고 이 폴더의 파일을 모두 올림
2. `config.js` 의 `API_URL` 에 1-4의 주소를 붙여 넣기
3. 저장소 [Settings] → [Pages] → Branch: `main` / `(root)` → Save
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 로 접속

### 3. 첫 수업 전
- 웹뷰어 **[🛠️ 교사]** → 어구 관리에 들어가 **관리자 비밀번호를 바로 정하기** (처음 적은 값이 비밀번호)
- 상단 오른쪽이 **● 시트 연결됨** 인지 확인
- 코드를 고치면 [배포 관리] → 연필 → **새 버전**으로 다시 배포 (주소는 그대로 유지)

## 앱 1 (BoW)
앱 1 소스는 아직 이 폴더에 없어서 기존 Apps Script 주소를 iframe으로 엽니다.
- 그 배포의 액세스가 '모든 사용자'가 아니면 학생 화면에 구글 로그인이 뜹니다 → 배포 설정을 바꿔 주세요.
- 앱 1 HTML이 있으면 `apps/app1.html`로 올리고, `</head>` 앞에 아래 두 줄을 넣은 뒤 `config.js`의 `APP1_URL`을 `"apps/app1.html"`로 바꾸면 됩니다.
  (앱 1이 시트를 쓰면 그 서버 함수를 `gas/Code.gs`의 `API` 목록에도 추가)

```html
<script src="../config.js"></script>
<script src="../gas-bridge.js"></script>
```

## 개인정보
- 학생 이름은 받지 않습니다. 학교명 + 번호(예: 260601)만 씁니다.
- `PSEUDONYMIZE: true`(기본)면 학교명은 브라우저에서 **S-xxxxxx 가명 코드**로 바뀐 뒤 전송됩니다. 시트에는 실제 학교명이 남지 않습니다.
- 학생 진행 상태는 각 기기의 브라우저(localStorage)에만 저장됩니다.
- 깃허브 저장소에는 학생 데이터가 올라가지 않습니다(데이터는 구글 시트에만).
